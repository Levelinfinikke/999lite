v.3

  • RUSH(ST) 연출 대폭 추가: 회전마다 다른 연출이 이어져요
  • 통상 배틀에 새 전개 추가 (패배 뒤 부활 등)
  • 기기 버튼 = PUSH, 레버 = PULL 전용으로 정리
  • 통상에서 버튼을 연타하면 빠르게 회전
  • 화면 확대 · 시점 이동 추가
  • 실전모드 추가: 자금과 목표를 정하고 도전, 결과 보고서
  • 컴플리트 기능 추가
  • 조작 버튼 배치 정리, 조작법에 개선사항 탭 추가
  • 모바일판: 화질은 그대로, 용량은 더 작게

v.2

  • AUTO 배속 추가 (x1 · x5 · x10 · x50)
  • HYPER 모드 추가 (진동 · LED 강화)
  • 소리 · 다크/라이트 · LED · 진동 아이콘 추가
  • 조작법(?) 버튼 추가
  • 영상의 안 쓰는 부분을 잘라 용량 축소
  • 아이폰 홈 화면 앱에서 화면이 가려지던 문제 수정

v.1

  • 첫 공개판: 기기 화면과 PLAY · RECORD 창
  • 회전율 설정, 회전수 · 당첨 기록과 그래프
  • PLAY 창의 실전모드 버튼으로 시작해요. 소지자금 · 목표 · 회전율을 정하면 목표 달성 확률을 보여 줘요.
  • 4엔 파친코 기준: 1,000엔 = 250구슬. 자금은 딴 구슬과 쓴 구슬을 엔으로 바꿔 계산해요.
  • 하루는 4,000회전. 다 돌리면 다음 날(DAY 2, 3 …)로 넘어가고 그래프에 표시돼요.
  • 자금이 바닥나면 실패, 목표에 닿으면 성공. 판정은 연출(RUSH 포함)이 끝난 뒤에 해요.
  • 끝나면 그래프와 함께 보고서가 나와요: 최대 수익 · 최대 손실 시점, 운이 상위 몇 %였는지 등.
  • 컴플리트: 하루에 순수하게 딴 구슬이 99,999를 넘으면 그날은 종료. 기기 버튼을 누르면 다음 날로 넘어가요.
  • 진행 중에 실전모드 버튼을 누르면 현재 상황 확인 · 포기를 할 수 있어요.
